# Politique de sécurité

## Versions supportées

| Version | Correctifs de sécurité |
| ------- | ---------------------- |
| 1.x | ✅ |
| Versions antérieures | ❌ |

## Signaler une vulnérabilité

**Ne créez pas d'issue publique pour signaler une vulnérabilité.**

Utilisez l'une des méthodes suivantes :

1. **Signalement privé GitHub** (recommandé) : onglet *Security* > *Report a vulnerability*.
   Le signalement n'est visible que des mainteneurs du projet.
2. **E-mail** : securite@example.com

Merci d'indiquer :

- la description de la vulnérabilité et son impact potentiel ;
- les étapes pour la reproduire (preuve de concept si possible) ;
- la version ou le commit concerné.

## Délais de traitement

| Étape | Délai cible |
| ----- | ----------- |
| Accusé de réception | 2 jours ouvrés |
| Première évaluation | 5 jours ouvrés |
| Correctif (gravité critique) | 30 jours |

Nous vous tiendrons informé de l'avancement et vous créditerons, si vous le
souhaitez, lors de la publication du correctif.
